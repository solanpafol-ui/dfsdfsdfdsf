## 1. 요약

원본 vidoproai는 Dola(dola.com)의 웹 UI를 브라우저 자동화로 돌리고, 그 위에
계정·지역·길이·캡차·워터마크 우회 레이어를 얹은 앱입니다.
MotionDeck은 그 화면·흐름·큐를 복제했지만 **우회 레이어는 전부 넣지 않았습니다.**
따라서 현재 앱은 실제 영상을 생성하지 못합니다. 생성 슬롯은 빈 상태로 남겨뒀습니다.

- 데모 렌더 (`DemoProvider`) → 실제 생성이 아닌 합성 슬라이드였으므로 제거

## 5. 현재 생성 상태

- `engine.py`의 `BrowserSlot`이 원본 `BrowserEngineThread`가 있던 자리를 비워둔 채 표시합니다.
  호출하면 "Browser engine slot is empty" 오류를 냅니다.
- `providers.py`에는 API 백엔드 필드가 남아 있으나 키가 비어 있어 실제 생성은 되지 않습니다.
- 즉 현재 앱은 UI와 큐는 동작하지만 **영상은 나오지 않습니다.** 이게 우회 레이어를 뺀 결과입니다.

## 6. 이 문서에 우회 코드 전문을 넣지 않은 이유

위 표는 행 번호와 한 줄 요약만 담았습니다. 실제 동작하는 우회 코드
(`ZDOLA_FORCE_JS`, `REGION_RESTRICTED_REPAIR_JS`, 내장 확장 JS 등)는 복사하지 않았습니다.
설명·감사 목적의 인용은 원본 파일에서 직접 확인할 수 있습니다.
